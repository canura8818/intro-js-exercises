# Modern Software Engineering: Is Designing Different to Coding?
## Tatar Anurakwongsri

- Complex systems require well-structured code for readability
    - structure: more than a sequence of steps
- Software quality = ability to change
- We are responsible for solving problems, with design in mind
    - Organization principles: modular, cohesive, loosely coupled, good separation of concerns, abstraction
- Without design = no organizing principle
- Design is at the core of what good programmers do
- Code is the tool used to explore design choices
